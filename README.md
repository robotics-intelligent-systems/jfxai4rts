# Recruitment Tracking System

minthcm.org is an open-source, AI-native HCM platform. OSC (acronym for Contract Tracking Tool). Frappe HR is an open source, modern, and easy-to-use HR and Payroll Software. Biometric Attendance Sync Tool (For ERPNext). ContractManager is a contract management software for the Jameica platform. OpenSign is an open source document e-signing solution. Paperless-AI is an AI-powered extension for Paperless-ngx that brings automatic document classification, smart tagging, and semantic search using OpenAI-compatible APIs and Ollama. deepdoctection is a Python library that orchestrates Scan and PDF document layout analysis, OCR and document and token classification. JuggleHire is a recruitment software solution designed to simplify the hiring process for busy professionals. SpotAxis is an open-source Applicant Tracking System to streamline your hiring process. HIRE (Human Intelligence Recruitment Engine) is a cutting-edge HR tech platform designed to streamline and modernize the recruitment process through artificial intelligence. PrismaIA is an open-source framework for bias-free candidate evaluation using LLMs. 

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
